# Sandbox

Somewhere to put things that are being looked at rather than kept: output from
another agent, a draft import CSV, an export being checked over.

Everything in here is ignored by git except this note, so nothing lands in the
repository by accident and nothing has to be tidied up before a commit.

Useful because a file here has a path that can be handed to Claude Code
directly — "read sandbox/example-trial.csv" — which beats pasting a long file
into a conversation and hoping the formatting survives.
